# QuickCart Advanced JavaScript

A practical JavaScript project based on a QuickCart e-commerce order management system. This project demonstrates modern JavaScript concepts and asynchronous programming.

## Technologies Used

- JavaScript (ES6+)
- HTML5
- CSS3
- Node.js

## Project Features

### Part A – Objects & ES6 Classes
- Prototypes and constructor functions
- ES6 classes and inheritance
- Arrow functions, template literals, destructuring, rest and spread operators

### Part B – Array Methods & Collections
- map(), filter(), reduce() and forEach()
- Map and Set
- Object.freeze() and Object.seal()

### Part C – JSON Handling
- JSON.stringify() and JSON.parse()
- JSON debugging and error handling

### Part D – Asynchronous JavaScript
- Event loop and callbacks
- Promises and async/await
- Promise combinators

### Part E – Performance & DOM Events
- Debouncing and throttling
- Memoization
- Event bubbling and delegation
- Dynamic product removal

### Part F – Final Integration
A complete order summary combining the concepts from all parts.

## How to Run

Install Node.js, then run:

```bash
npm start
```

This runs Parts A, B, C, D and F.

For Part E, open `part-e-optimization-events/index.html` using Live Server in VS Code.
